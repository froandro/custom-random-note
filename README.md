# Custom Random Note Plugin for Obsidian

Этот плагин позволяет открывать случайные заметки из выбранных папок в вашем хранилище Obsidian, а также ведёт историю просмотренных заметок. Полезно для вдохновения, повторения или исследования старых записей.

---

## 🌟 Функции

- 🔀 **Открытие случайной заметки** — открывает случайную `.md` заметку из указанных папок.
- 📁 **Гибкий выбор папок** — задайте, какие папки включать или исключать из случайного выбора.
- 🕰 **История открытых заметок** — отслеживайте, какие заметки вы открывали (вручную или случайно).
- 🎯 **Автоматическое открытие при запуске** — автоматически открывает случайную заметку при старте Obsidian.
- 🔐 **Скрытие путей в истории** — опция для приватности (например, при демонстрации экрана).
- 🧹 **Очистка истории** — возможность очистить историю вручную или при отключении плагина.

---

## ⚙️ Установка

### Способ 1: Через внутренний менеджер плагинов Obsidian (⚠️ пока недоступно)

1. Откройте Obsidian.
2. Перейдите в **Настройки → Плагины → Community plugins → Browse**.
3. Найдите `Custom Random Note` и установите его.

> ⚠️ Плагин пока может быть недоступен в официальном репозитории. В таком случае используйте ручную установку.

### Способ 2: Ручная установка

1. Скачайте файл `main.js` (и, при необходимости, `manifest.json`, `styles.css`).
2. В папке вашего хранилища Obsidian перейдите в `.obsidian/plugins/`.
3. Создайте папку `custom-random-note`.
4. Поместите туда файл `main.js`.
5. Перезапустите Obsidian.
6. Перейдите в **Настройки → Плагины** и включите **Custom Random Note**.

## 🛠 Настройка

После активации плагина откройте его настройки:

1. Перейдите в **Настройки → Плагины → Custom Random Note**.
2. Настройте параметры:

| Настройка | Описание |
|---------|--------|
| **Auto-open random note on startup** | Автоматически открывать случайную заметку при запуске Obsidian. |
| **Track all opened notes** | Добавлять в историю **все** открываемые заметки, а не только случайные. |
| **Hide file paths in history** | Скрывать пути к файлам в истории (для приватности). |
| **Maximum history items** | Максимальное количество записей в истории (от 5 до 50). |
| **Allowed Folders** | Папки, из которых будут выбираться случайные заметки. |
| **Ignored Folders** | Папки, которые будут исключены из случайного выбора. |
| **Clear history on plugin unload** | Очищать историю при отключении плагина. |
| **Clear History Now** | Кнопка для немедленной очистки истории. |

## 🎯 Использование

- **Открыть случайную заметку**:
  - Через команду: `Ctrl/Cmd + P` → "Open random note from folders".
  - Через иконку кубика (🎲) на панели слева.
- **Просмотреть историю**:
  - Нажмите на иконку часов (🕒) на панели слева.
  - Или используйте команду "Open Note History".
  - Из истории можно повторно открыть любую заметку.

---

## 🧩 Интерфейс истории

- Заголовок: **History of Opened Notes**
- Отображаются:
  - Название заметки.
  - Тип открытия: *Random* или *Manual*.
  - Путь (если не скрыт).
  - Кнопка **Open** для быстрого доступа.

---

## 🗑 Очистка данных

- При отключении плагина история **не удаляется** по умолчанию.
- Включите опцию **Clear history on plugin unload**, если хотите автоматическую очистку.
- Или используйте кнопку **Clear History Now**.
